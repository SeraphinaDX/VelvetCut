# VelvetCut 0.7.0 Beta — Keyframed titles

## What changed
Titles can move, fade or change size during a video clip. Position is a normalized X/Y centre point; scale and opacity are interpolated linearly between keyframes. These per-clip edits do not change original footage.

## Editing a title animation
1. Import a video, insert it, select that clip, and enter a title in the Inspector's **Title** tab. Click **Apply to selected clip**.
2. Seek near the start. Drag the purple **Drag title** outline directly in the preview; release to save a position keyframe.
3. Seek later and drag again. Open the **Motion** tab, set scale and opacity, and click **Add / update keyframe** to save their values.
4. Use **Previous keyframe**, **Next keyframe**, **Remove at playhead**, or **Clear all keyframes** to manage motion. Gold notches in the timeline show keyframe locations.
5. Press Play to render and view a composited proxy; Export MP4 to render the same animation at export resolution.

Keyframe timestamps are relative to the clip's in-point. Splitting and trimming re-map keyframes; undo/redo and project saving preserve them. Existing .velvetcut project files remain readable. When keyframes exist, they override older title entrance animation presets. Titles display only within the duration set by the Inspector.

## Testing
```sh
go test -race ./editor ./media

```

## Limitations
The drag outline is a guide; during a drag, the underlying FFmpeg preview still updates after mouse release. Playback uses a rendered proxy rather than live GPU compositing. Keyframes currently animate **titles**, not the whole image or multi-layer graphics. The full desktop interface needs testing on Linux; package tests alone cannot verify Fyne mouse events.
